2. Auto-annotate

                    

                        
                        
                        
                        
                    

                    

                        How Run Model works
                        
    
                            
  • Indices are 0-based reference positions in the JSON (not batch file numbers).
    • 
                            
  • Annotate — Qwen only — every target through Qwen P3 + post-LLM (no Duo / Reranker).
    • 
                            
  • Annotate — Cascade (incl. Qwen) — Duo Zero Faute (MiniLM + DeBERTa Large) → Reranker undetermined (≥0.70) → else Qwen P3 + post-LLM. Qwen is the last stage of the cascade. Thresholds in models/cascade_v8/config.json.
    • 
                            
  • Compare — Qwen ↔ Cascade (incl. Qwen) — runs those two pipelines only; same label → auto-annotate; mismatch → needs review with side-by-side detail.
    • 
                            
  • Time estimate: shown only after a first completed Run Model in the same mode (Qwen only and Cascade are calibrated separately). No theoretical guess on a cold start.
    • 
                            
  • Run Model resumes at the first incomplete reference and skips finished targets — unless you choose to overwrite.
    • 
                            
  • Re-annotate: if the range is partially or fully annotated, a confirmation asks whether to overwrite.
    • 
                            
  • Disagreements (human / rejected / compare_disagree) are not final — retried on the next run.
    • 
                        

                    

                    
                    Available when checklist is valid (Cascade weights + Qwen/Ollama for Cascade & Compare; Qwen alone needs Ollama).
