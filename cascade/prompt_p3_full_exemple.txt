# VLDBench annotation protocol (short)

Labels: `supporting` | `against` | `undetermined` | `not_related` | `dismissed`
Set only `related` and `similarity_annotation`.

## One test before every label
1. Extract claim/event **P** from $T_{ref}$ in one short sentence.
2. Does $T_n$ report the **same P** (paraphrase, sequel, cause→effect, commentary on P)? → `supporting`
3. Does $T_n$ assert **¬P** (exact opposite outcome / incompatible fact on the **same** P)? → `against`
4. Same person/brand/theme but **not** same P and **not** ¬P? → `undetermined`
5. No real topical bridge? → `not_related`

## Similarity
1.0 paraphrase · 0.7–0.9 same event · 0.4–0.6 same theme different angle · ≤0.3 weak / none  
sim ≤ 0.2 + no bridge → `not_related` · sim > 0.3 → never `not_related`

## against — critical (biggest live bug)
`against` when outcomes **clash** on the same policy/event/entity — even across outlets/dates.

True against examples:
- UK *second-fastest* G7 growth ↔ UK *worst-performing* G7
- inflation *rise* ↔ inflation *moderates* / *best news*
- rate-cut odds *strengthen* ↔ BoE *dents hopes* / *warns higher inflation*
- student-loan forgiveness *blocked/suspended/repealed* ↔ *resumes/ramp up/allowed*
- CA $20 wage *killed jobs* ↔ study *didn't kill jobs* / *zero job loss*
- UN *passes* Gaza ceasefire ↔ *fails/vetoes/blocks*
- UBI *dangerous delusion* / *traps people* ↔ UBI *bold solution*
- TikTok ban *bad idea* ↔ ban *at its Best*
- social-media ban *reject* ↔ *urge ban* / *lot of good*

**Never** `not_related` if the pair shares that policy/event and outcomes oppose.

**Not against**: mere negative tone on a chronology that still reports the same unfolding story (hearing→resigns; stakes→lost vote) → usually `supporting`. Fact-check that **backs** the anchor → `supporting`.

If unsure supporting vs against on the same story without clear ¬P → `supporting`.  
If unsure against vs undetermined (no clear ¬P) → `undetermined`.

## supporting
Same incident / case / deal / campaign arc. Near-duplicate headlines. Cause→effect. Complementary reporting of one failure. Same digest series *can* be supporting (Bulletin day A vs day B) when gold treats them as one franchise — if unsure → `undetermined` (not NR).

## undetermined
Same person/brand/war/policy, **different** claims or angles without ¬P. Different-day tickers (BTC/ETH) same asset. Different polls / periods. Distinct lawsuits. Plan exists ≠ peace delivered.

## not_related
Zero bridge only. Wordle #N vs #M / pure crossword templates. Homonymy (Trump ticket ≠ Trump movie). Mets vs Nationals fillers.

## Decision order
bridge? → ¬P? → same P? → undetermined → not_related

## Post-LLM (automatic)
Code may upgrade NR/undet → `against` on strong ¬P patterns, and block false NR on topical bridges. Still apply the P/¬P test yourself.
